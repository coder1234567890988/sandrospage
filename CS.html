Video game development:

I have made a lot of different games in my free time using the Godot game engine, which are all posted on itch.io. They were all made for game competitions hosted online. Generally I choose Godot as a game engine, as I feel it is a lot more lightweight and fast compared to more tradional ones like Unity or Unreal Engine [this is especially useful as my computer is not particularly powerful]. I also feel it is generally much easier to use and programme in.

Blok

This game is my most complete one so far. It is a small puzzle platformer and was made in around 2 days. It's based around a simple 'swapping' mechanic that I explore over the rest of the levels. Although it's not very long (and new mechanics could have been included), I still enjoyed making it a lot. Programming wise it is not too complicated other than having setting up to set up modular code for organizing levels. Generally I feel it is easier to programme puzzle games, as you just need to set up the initial logic once for the puzzles to work and it can then be reapplied to every level.
 Visit the website with the game

Mecon

This game is my most recent one. It is an exploration game but is very short. It took around 7 days. This game I wanted to focus more on art and environment as my other game Blok was quite minimalist, and I think I succeeded in that regard however it was as a result a lot more time consuming to make. Programming wise Godot does make it quite easy to add parallax effect and animate however it took a while to get the physics for the robot correct.
Visit the website with the game

Spinatus

This game I have spent the most time on, which is about ~20 days. It is a topdown shooter boss rush. For this game I had to think a lot about how to apply modular code such that it can be applied for every boss including the player, examples of this might include a physical body script that deals with collisions and appearance or a hp script that deals with keeping tracking of a health value along with setting up hit frames and hit detections.
Visit the website with the game
